# Gpt Repositories

## Thought Pad [![View Repo](https://img.shields.io/badge/view-repo-green)](https://github.com/danielrosehill/Thought-Pad)
Linux desktop application that provides a two-stage process for creating notes from dictated speech (first stage, transcription via Whisper API; second stage light text formatting). Exports to markdown docs.


## Prompt Library [![View Repo](https://img.shields.io/badge/view-repo-green)](https://github.com/danielrosehill/Prompt-Library)
A repository of prompts I've used when working with LLMs as well as some example outputs and notes

## Toxic Gpt [![View Repo](https://img.shields.io/badge/view-repo-green)](https://github.com/danielrosehill/Toxic-GPT)
Joke configuration for a downtrodden LLM assistant for those needing a break from enforced AI positivity

## Chatgpt Agents Notes [![View Repo](https://img.shields.io/badge/view-repo-green)](https://github.com/danielrosehill/ChatGPT-Agents-Notes)
Notebook for ChatGPT agents

## Chatgpt Plugins [![View Repo](https://img.shields.io/badge/view-repo-green)](https://github.com/danielrosehill/ChatGPT-Plugins)
Daniel Rosehill's public plugins for ChatGPT (adapted from his Claude Code marketplace) as an importable plugin marketplace catalogue

## Rtl Conformity Skills [![View Repo](https://img.shields.io/badge/view-repo-green)](https://github.com/danielrosehill/RTL-Conformity-Skills)
Agent skills that keep Hebrew/Arabic right-to-left across email (Gmail, Resend), Google Docs/Sheets/Slides/Drive, calendar and generated files. Claude plugin, also works in ChatGPT.

## Claude Chatgpt Importer Plugin [![View Repo](https://img.shields.io/badge/view-repo-green)](https://github.com/danielrosehill/Claude-ChatGPT-Importer-Plugin)
Claude Code plugin: import ChatGPT conversations via the browser into Markdown, JSON or PDF with turns marked, artifacts extracted and metadata recorded
