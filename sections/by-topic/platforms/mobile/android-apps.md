# Android-apps Repositories


## Adb Keep Awake [![View Repo](https://img.shields.io/badge/view-repo-green)](https://github.com/danielrosehill/adb-keep-awake)
Scripts to prevent Android phones from sleeping while connected via USB (keeps ADB working)

## Ptouch Cube Print Bridge [![View Repo](https://img.shields.io/badge/view-repo-green)](https://github.com/danielrosehill/ptouch-cube-print-bridge)
Turn a Brother PT-P710BT (P-Touch Cube Plus) into a networked label printer: USB print bridge on a home server + web-app integration snippets

## Android Media Importer [![View Repo](https://img.shields.io/badge/view-repo-green)](https://github.com/danielrosehill/Android-Media-Importer)
Claude Code plugin: move or copy media from a connected Android phone using user-defined mappings, MIME-based routing, optional date-folder + orientation-split layouts.

## Voxcast [![View Repo](https://img.shields.io/badge/view-repo-green)](https://github.com/danielrosehill/Voxcast)
Speak. Reshape. Send. — A serious voice-to-text Android app powered by OpenRouter + Gemini.

## Family Page [![View Repo](https://img.shields.io/badge/view-repo-green)](https://github.com/danielrosehill/Family-Page)
Simple Android APK paging button

## Android Selection Case Converter [![View Repo](https://img.shields.io/badge/view-repo-green)](https://github.com/danielrosehill/Android-Selection-Case-Converter)
Android text-selection menu: UPPERCASE or ChAoS cAsE, on device, no permissions

## F Droid Public Repo [![View Repo](https://img.shields.io/badge/view-repo-green)](https://github.com/danielrosehill/F-Droid-Public-Repo)
Public F-Droid repo for Daniel Rosehill's Android apps, served from Cloudflare R2 at apps.bydanielrosehill.com

## Android Thin Fork Autosync [![View Repo](https://img.shields.io/badge/view-repo-green)](https://github.com/danielrosehill/Android-Thin-Fork-Autosync)
Template for a thin downstream fork of an active Android app: narrow hooks, weekly auto-merge of upstream releases, seam checks, signed release APKs via GitHub Actions
